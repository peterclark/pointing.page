# Raw Idea: Voting & Reveal Flow

## Feature Description

This is the next feature in the product roadmap after "Room Creation & Management" which has been completed and deployed to production at https://pointing.page.

Feature context:
- Users need to be able to cast votes on stories using the point scale selected during room creation (Fibonacci or T-shirt sizes)
- Votes should remain hidden until the room leader reveals them
- The feature should support the existing anonymous user pattern (using localStorage for participant_id)
- Must integrate with existing database schema (rooms, participants, stories, votes tables)

## Status

Raw idea captured. Ready for requirements research phase.
